What it does

The MVP covers spec steps 1–5: discovery, messaging, mesh relay, storage, chat UI and SOS.

📡

Auto-discovery

Finds nearby LinkMesh phones over BLE and connects to the strongest ones automatically.

🔁

Mesh relay

Every phone is a node. Messages hop up to 5 devices to reach someone out of range.

✓✓

Delivery receipts

Shows ✓ sent, ⇄ relayed and ✓✓ delivered, plus "via N devices" for each message.

📦

Store & forward

If a chain breaks, messages wait and continue when a path comes back.

🆘

SOS broadcast

One tap repeats an alert with GPS coordinates to every phone in the mesh.

🔋

Battery-aware

Scans in short bursts, limits connections to 5, and keeps no internet connection open.

How it works

Every phone runs both BLE roles at once. As a peripheral it advertises the LinkMesh service and accepts frames. As a central it scans, connects and writes frames to peers. The routing layer only uses a transport interface, so WiFi Direct and LoRa can be added later.

On every received message

  1. Seen this id before? Ignore it.
  2. Addressed to me? Store it and send an ack back.
  3. An ack for me? Mark the message ✓✓ delivered.
  4. Otherwise, if hop_count < max_hops, relay it with hop_count + 1.
  5. Keep it in the relay buffer for 15 min and replay it to new peers.

Install & test

You need two or more Android 8+ phones. Emulators have no Bluetooth radio.

Install the APK

  1. Download LinkMesh.apk on each phone.
  2. Allow "Install unknown apps". If Play Protect warns about a test build, choose Install anyway.
  3. Open the app and allow Nearby devices and Location.
  4. Tap the profile icon and give each phone a name.

Test scenarios

  1. Direct: two phones side by side should go to ✓✓.
  2. Relay: put A and C out of range with B in the middle. Expect "via 1 device".
  3. Drop: turn B off, send, then turn B back on. The message should still arrive.
  4. SOS: tap SOS. Every phone should get an alert with coordinates.

Keep the app open on screen: background mode arrives in Phase 2. Want to build it yourself? See the README.
